React’te Kontrollü & Kontrolsüz Elementler ve API İstekleri ⚙️🌐

React uygulamalarında form elemanları (input, select, textarea vb.) kullanıcıyla etkileşim kurmanın temel yollarındandır. Bu elemanların kontrolünü nasıl yönettiğimiz, uygulamanın davranışını doğrudan etkiler. Ayrıca, kullanıcıdan alınan veriler genellikle bir API’a gönderilir — dolayısıyla bu konular birbiriyle doğrudan ilişkilidir.

1. Kontrollü ve Kontrolsüz Elementler Nedir?

React'te form elemanları iki şekilde yönetilir:

  • Kontrollü (Controlled): Input değeri React state tarafından yönetilir.
  • Kontrolsüz (Uncontrolled): Input değeri doğrudan DOM üzerinden yönetilir.

React’in “tek yönlü veri akışı” mantığı nedeniyle kontrollü bileşenler tercih edilir. Ancak basit veya performans odaklı durumlarda kontrolsüz bileşenler de kullanılabilir.

2. Kontrollü Form Elementleri ✏️

Kontrollü formda input değeri state’te tutulur. Yani input’un “value” özelliği React tarafından yönetilir. 


import React, { useState } from "react";

const ControlledInput: React.FC = () => {
  const [name, setName] = useState<string>("");

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    alert(`Girilen isim: ${name}`);
  };

  return (
    <form onSubmit={handleSubmit} style={{ textAlign: "center", marginTop: "20px" }}>
      <label>İsminizi girin:</label><br />
      <input
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Adınızı yazın..."
      />
      <br /><br />
      <button type="submit">Gönder</button>
    </form>
  );
};

export default ControlledInput;

Bu örnekte input’un değeri tamamen React state tarafından kontrol edilir. Her karakter girişi state’i günceller, state de input’un value prop’unu değiştirir.

💡 Avantaj: Tüm form verilerini React kontrol eder, bu da doğrulama, temizleme ve form resetleme işlemlerini kolaylaştırır.

3. Kontrolsüz Form Elementleri 🧩

Kontrolsüz formlarda React state kullanılmaz. Bunun yerine useRef() ile DOM’daki input değerine doğrudan erişilir. 


import React, { useRef } from "react";

const UncontrolledInput: React.FC = () => {
  const inputRef = useRef<HTMLInputElement>(null);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (inputRef.current) {
      alert(`Girilen değer: ${inputRef.current.value}`);
    }
  };

  return (
    <form onSubmit={handleSubmit} style={{ textAlign: "center", marginTop: "20px" }}>
      <label>Kontrolsüz input örneği:</label><br />
      <input type="text" ref={inputRef} placeholder="Bir değer girin..." />
      <br /><br />
      <button type="submit">Gönder</button>
    </form>
  );
};

export default UncontrolledInput;

Burada React state yerine ref ile input’un değerine erişiyoruz. React input’un değerini yönetmez, sadece form gönderildiğinde DOM’dan okur.

💡 Avantaj: Daha az render gerçekleşir, performans artar. ⚠️ Dezavantaj: Form verisini yönetmek veya doğrulamak daha zordur.

4. React Binding (Two-Way Data Binding) 🔄

React’te veriler genellikle “tek yönlü” akar (parent → child). Ancak state ile input değerini bağlayarak iki yönlü veri akışı (two-way binding) sağlayabiliriz. 


import React, { useState } from "react";

const TwoWayBinding: React.FC = () => {
  const [message, setMessage] = useState<string>("Merhaba React!");

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <input
        type="text"
        value={message}
        onChange={(e) => setMessage(e.target.value)}
      />
      <p>Canlı Görünüm: {message}</p>
    </div>
  );
};

export default TwoWayBinding;

Bu örnekte kullanıcı input’a her yazdığında message state güncellenir ve aynı anda ekrana yansır. Bu, “two-way binding” (çift yönlü veri bağlama) olarak adlandırılır.

5. React ile API’a İstek Atma 🌐

Gerçek dünyadaki uygulamalarda formlardan alınan veriler genellikle bir API’a gönderilir veya API’dan veri çekilir. React’te bu işlem fetch veya axios kütüphanesi ile yapılabilir.

👉 API’dan Veri Çekme


import React, { useEffect, useState } from "react";

type Post = {
  id: number;
  title: string;
  body: string;
};

const FetchPosts: React.FC = () => {
  const [posts, setPosts] = useState<Post[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch("https://jsonplaceholder.typicode.com/posts");
        const data = await response.json();
        setPosts(data.slice(0, 5)); // İlk 5 post
      } catch (error) {
        console.error("Veri çekme hatası:", error);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, []);

  if (loading) return <p>Yükleniyor...⏳</p>;

  return (
    <div>
      <h2>Post Listesi</h2>
      <ul>
        {posts.map((p) => (
          <li key={p.id}>
            <strong>{p.title}</strong>
          </li>
        ))}
      </ul>
    </div>
  );
};

export default FetchPosts;

Bu örnekte API’dan veri çektik ve state’e kaydettik. React state değişimini fark edip UI’ı otomatik olarak güncelledi.

👉 API’a Veri Gönderme (POST İsteği)


import React, { useState } from "react";

const PostForm: React.FC = () => {
  const [title, setTitle] = useState<string>("");
  const [content, setContent] = useState<string>("");
  const [message, setMessage] = useState<string>("");

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    try {
      const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ title, body: content }),
      });

      if (response.ok) {
        const data = await response.json();
        setMessage(`Başarılı! Yeni Post ID: ${data.id}`);
      }
    } catch (error) {
      setMessage("Hata oluştu!");
    }
  };

  return (
    <form onSubmit={handleSubmit} style={{ textAlign: "center", marginTop: "20px" }}>
      <h3>Yeni Gönderi Oluştur</h3>
      <input
        type="text"
        placeholder="Başlık"
        value={title}
        onChange={(e) => setTitle(e.target.value)}
      /><br /><br />
      <textarea
        placeholder="İçerik"
        value={content}
        onChange={(e) => setContent(e.target.value)}
      /><br /><br />
      <button type="submit">Gönder</button>
      <p>{message}</p>
    </form>
  );
};

export default PostForm;

Bu örnekte kullanıcı form doldurup gönderdiğinde API’a POST isteği atıyoruz. Bu yapı, gerçek dünyada form tabanlı veri gönderimlerinin temelidir.

📘 Özet

  • Kontrollü Elemanlar: React state tarafından yönetilir. Doğrulama ve reset işlemleri kolaydır.
  • Kontrolsüz Elemanlar: DOM üzerinden yönetilir. Performans açısından hızlıdır.
  • React Binding: State ile input değerini bağlayarak iki yönlü veri akışı sağlar.
  • API İstekleri: fetch veya axios ile veri çekme ve gönderme işlemleri yapılır.
