React JS Giriş 🚀

React, kullanıcı arayüzleri oluşturmak için kullanılan, component tabanlı bir JavaScript kütüphanesidir. Facebook tarafından geliştirilmiş olup, tek sayfa uygulamalar (Single Page Applications) oluşturmak için oldukça idealdir. TypeScript ile birlikte kullanıldığında, daha güvenli ve ölçeklenebilir uygulamalar geliştirilmesini sağlar.

1. Component Nedir?

React uygulamaları, birçok küçük bileşenden (component) oluşur. Bu bileşenler, bir arayüzün yeniden kullanılabilir parçalarıdır. Her component, kendi görünümünü ve davranışını yönetir. Component yapısı, projenin okunabilirliğini ve sürdürülebilirliğini artırır.

Örnek: Basit bir selamlama bileşeni:


import React from "react";

type GreetingProps = {
  name: string;
};

const Greeting: React.FC<GreetingProps> = ({ name }) => {
  return <h2>Merhaba, {name}! 👋</h2>;
};

export default Greeting;

Yukarıdaki örnekte, Greeting adlı bir component tanımladık. Component, dışarıdan bir name prop’u alıyor ve ekrana bir selamlama mesajı basıyor.

2. Props'lara Giriş

Props (properties), component’ler arasında veri taşımamızı sağlayan mekanizmadır. React’te veri akışı genellikle tek yönlüdür (parent → child). Bu, uygulama verilerinin yönetimini daha tahmin edilebilir hale getirir.

Örnek: Props kullanımı


import React from "react";

type UserCardProps = {
  username: string;
  age: number;
};

const UserCard: React.FC<UserCardProps> = ({ username, age }) => {
  return (
    <div style={{ border: "1px solid #ccc", padding: "10px", borderRadius: "8px" }}>
      <h3>Kullanıcı Adı: {username}</h3>
      <p>Yaş: {age}</p>
    </div>
  );
};

export default UserCard;

Bu örnekte UserCard component’i iki prop alıyor: username ve age. Props’lar, bileşenlerin yeniden kullanılabilirliğini sağlar.

Kullanımı:


import React from "react";
import UserCard from "./UserCard";

const App: React.FC = () => {
  return (
    <div>
      <UserCard username="Hakan" age={30} />
      <UserCard username="Ayşe" age={25} />
    </div>
  );
};

export default App;

3. Semantic UI CSS Kütüphanesi

React projelerinde CSS framework'leri kullanmak, hızlı ve şık arayüzler geliştirmenizi sağlar. Semantic UI, bileşen tabanlı bir CSS framework’tür ve React ile mükemmel uyum sağlar.

Kurulum:

npm install semantic-ui-css

Kullanım:


import 'semantic-ui-css/semantic.min.css';
import { Button } from 'semantic-ui-react';

const App: React.FC = () => {
  return (
    <div style={{ padding: "20px" }}>
      <Button primary>Kaydet</Button>
      <Button secondary>İptal</Button>
    </div>
  );
};

export default App;

Bu örnekte, Semantic UI React ile hazır buton component’lerini kullandık. Bu sayede, stil dosyalarıyla uğraşmadan modern arayüzler oluşturabiliriz.

4. Component Oluşturma

Component’ler iki şekilde oluşturulabilir:

  • Function Component (günümüzde en çok tercih edilen)
  • Class Component (eski React sürümlerinde yaygın)

Function Component Örneği:


const WelcomeMessage: React.FC = () => {
  return <h1>React Eğitimine Hoş Geldiniz! 🚀</h1>;
};

Class Component Örneği (güncel projelerde önerilmez):


import React, { Component } from "react";

class WelcomeMessage extends Component {
  render() {
    return <h1>React Eğitimine Hoş Geldiniz! 🚀</h1>;
  }
}

export default WelcomeMessage;

Function component’ler daha sade, test edilebilir ve Hooks kullanımıyla çok daha güçlüdür.

5. Uygulama Çalışması

Şimdi tüm öğrendiklerimizi küçük bir örnekle birleştirelim 👇 


import React from "react";
import "semantic-ui-css/semantic.min.css";
import { Card, Button } from "semantic-ui-react";

type ProductProps = {
  name: string;
  price: number;
  inStock: boolean;
};

const ProductCard: React.FC<ProductProps> = ({ name, price, inStock }) => {
  return (
    <Card>
      <Card.Content>
        <Card.Header>{name}</Card.Header>
        <Card.Meta>Fiyat: ₺{price}</Card.Meta>
        <Card.Description>
          {inStock ? "Stokta var ✅" : "Stokta yok ❌"}
        </Card.Description>
      </Card.Content>
      <Card.Content extra>
        <Button color="green">Sepete Ekle</Button>
      </Card.Content>
    </Card>
  );
};

const App: React.FC = () => {
  return (
    <div style={{ display: "flex", gap: "1rem", padding: "20px" }}>
      <ProductCard name="Kulaklık" price={500} inStock={true} />
      <ProductCard name="Klavye" price={350} inStock={false} />
    </div>
  );
};

export default App;
