React ile Redux’a Giriş 🗂️

React uygulamalarında state yönetimi büyüdükçe karmaşıklaşır. Redux, merkezi bir store üzerinden state’i yönetmemizi sağlayan güçlü bir kütüphanedir. Bu sayede component’ler arası veri paylaşımı daha düzenli ve öngörülebilir olur.

1. Redux Store Nedir? 🏬

Redux store, uygulamanın tüm state’lerini tek bir yerde tutan merkezi yapıdır. State değişimleri yalnızca actions ve reducers üzerinden yapılır. 


// store.ts
import { configureStore } from "@reduxjs/toolkit";
import counterReducer from "./counterSlice";

export const store = configureStore({
  reducer: {
    counter: counterReducer,
  },
});

// RootState ve AppDispatch tipleri
export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;

2. Redux Actions 📩

Action, state’i değiştirmek için gönderilen planlı talimattır. Genellikle bir type ve isteğe bağlı payload içerir. 


// counterSlice.ts
import { createSlice, PayloadAction } from "@reduxjs/toolkit";

type CounterState = { value: number };

const initialState: CounterState = { value: 0 };

const counterSlice = createSlice({
  name: "counter",
  initialState,
  reducers: {
    increment: (state) => { state.value += 1; },
    decrement: (state) => { state.value -= 1; },
    incrementByAmount: (state, action: PayloadAction<number>) => {
      state.value += action.payload;
    },
  },
});

export const { increment, decrement, incrementByAmount } = counterSlice.actions;
export default counterSlice.reducer;

Burada increment, decrement ve incrementByAmount birer action’dır.

3. Redux Reducers ⚙️

Reducer, action geldiğinde state’in nasıl değişeceğini belirler. Önemli: Reducer saf bir fonksiyon olmalıdır (pure function). 


// Yukarıdaki counterSlice zaten reducer’ı oluşturuyor
// increment action geldiğinde state.value 1 artar
// decrement action geldiğinde state.value 1 azalır

4. Store Subscriptions 🔔

Redux store’a abone olarak state değişikliklerini dinleyebiliriz. Genellikle React içinde useSelector hook’u ile yapılır. 


import { useSelector } from "react-redux";
import { RootState } from "./store";

const CounterDisplay: React.FC = () => {
  const count = useSelector((state: RootState) => state.counter.value);

  return <h2>Count: {count}</h2>;
};

export default CounterDisplay;

5. Redux Kurulum 🛠️

Redux ve React ile entegrasyonu için gerekli paketler: 


npm install @reduxjs/toolkit react-redux

Root component’te Provider ile store’u React uygulamasına bağlamamız gerekir: 


import React from "react";
import ReactDOM from "react-dom/client";
import { Provider } from "react-redux";
import { store } from "./store";
import App from "./App";

const root = ReactDOM.createRoot(document.getElementById("root") as HTMLElement);
root.render(
  <Provider store={store}>
    <App />
  </Provider>
);

6. useDispatch 🚀

Action’ları dispatch etmek için useDispatch hook’u kullanılır. Bu sayede reducer’ı tetikleyebiliriz. 


import { useDispatch } from "react-redux";
import { increment, decrement, incrementByAmount } from "./counterSlice";

const CounterControls: React.FC = () => {
  const dispatch = useDispatch();

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <button onClick={() => dispatch(increment())}>Arttır</button>
      <button onClick={() => dispatch(decrement())} style={{ marginLeft: "10px" }}>Azalt</button>
      <button onClick={() => dispatch(incrementByAmount(5))} style={{ marginLeft: "10px" }}>+5</button>
    </div>
  );
};

export default CounterControls;

7. useSelector 👀

State’i component içinde okumak için useSelector kullanılır. Bu hook, store’a abone olur ve ilgili state değiştiğinde component yeniden render edilir. 


import { useSelector } from "react-redux";
import { RootState } from "./store";

const CounterValue: React.FC = () => {
  const count = useSelector((state: RootState) => state.counter.value);

  return <h2 style={{ textAlign: "center" }}>Güncel Sayı: {count}</h2>;
};

export default CounterValue;

📘 Özet

  • Store: Uygulamanın merkezi state deposudur.
  • Actions: State’i değiştirmek için gönderilen talimatlardır.
  • Reducers: Gelen action’a göre state’i günceller.
  • useDispatch: Action’ları store’a gönderir.
  • useSelector: Store’dan state okumamızı sağlar.
  • Provider: Store’u React uygulamasına bağlar.
