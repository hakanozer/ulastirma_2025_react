React Custom Hooks ve React Hooks’a Giriş 🪝

React Hooks, fonksiyon tabanlı component’lerde state ve lifecycle yönetimini yapmamızı sağlar. Ayrıca, Custom Hooks oluşturarak tekrar eden mantıkları tek bir yerde toplarız. Bu sayede kod daha temiz, yeniden kullanılabilir ve test edilebilir hale gelir.

1. Custom Hooks Ne İşe Yarar? ⚙️

Custom Hook’lar, React’in yerleşik hook’larını (useState, useEffect, vs.) kendi özel mantığımızla birleştirmemizi sağlar. Örneğin API isteği atmak, form verilerini yönetmek veya localStorage işlemleri gibi tekrarlanan yapıları soyutlamak için kullanılır. 


// useFetch.ts (Custom Hook)
import { useEffect, useState } from "react";
import axios from "axios";

export const useFetch = (url: string) => {
  const [data, setData] = useState<any[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await axios.get(url);
        setData(response.data);
      } catch (err) {
        setError("Veri çekme hatası oluştu.");
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
};


// App.tsx
import React from "react";
import { useFetch } from "./useFetch";

const App: React.FC = () => {
  const { data, loading, error } = useFetch("https://jsonplaceholder.typicode.com/users");

  if (loading) return <p>Yükleniyor...</p>;
  if (error) return <p>{error}</p>;

  return (
    <div>
      <h2>Kullanıcı Listesi</h2>
      <ul>
        {data.map((user) => (
          <li key={user.id}>{user.name}</li>
        ))}
      </ul>
    </div>
  );
};

export default App;

💡 Avantajı: Artık bu mantığı başka component’lerde de tekrar yazmadan kullanabiliriz.

2. Birden Fazla Custom Hook Kullanımı 🔁

Bir component içinde birden fazla custom hook kullanmak mümkündür. Örneğin biri veri çekmek için, diğeri de sayfa başlığı değiştirmek için olabilir. 


// useTitle.ts
import { useEffect } from "react";

export const useTitle = (title: string) => {
  useEffect(() => {
    document.title = title;
  }, [title]);
};


// App.tsx
import React from "react";
import { useFetch } from "./useFetch";
import { useTitle } from "./useTitle";

const App: React.FC = () => {
  const { data } = useFetch("https://jsonplaceholder.typicode.com/posts");
  useTitle("Post Listesi");

  return (
    <div>
      <h2>Toplam Post Sayısı: {data.length}</h2>
    </div>
  );
};

export default App;

💡 Birden fazla custom hook, component’in farklı görevlerini mantıksal olarak bölmenizi sağlar.

3. React Hooks’a Başlıyoruz ⚛️

React Hooks, class component’lerde bulunan state ve lifecycle özelliklerini fonksiyonel component’lere taşır. En yaygın kullanılan hook’lar:

  • useState – State yönetimi
  • useEffect – Yan etkilerin (API çağrısı, timer vb.) yönetimi
  • useRef – DOM erişimi veya mutable değişkenler
  • useContext – Global state paylaşımı
  • Custom Hook – Kendi mantığımızı modüler hale getirme

4. useState Hook 🎛️

useState, bir component içinde state tanımlamak için kullanılır. 


import React, { useState } from "react";

const Counter: React.FC = () => {
  const [count, setCount] = useState(0);

  return (
    <div style={{ textAlign: "center" }}>
      <h2>Sayaç: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Arttır</button>
      <button onClick={() => setCount(count - 1)} style={{ marginLeft: "10px" }}>Azalt</button>
    </div>
  );
};

export default Counter;

💡 setCount çağrıldığında component yeniden render edilir ve yeni state UI’da görünür.

5. useState ve Form Elemanları 📝

Form verilerini yönetmek için useState sıkça kullanılır. 


import React, { useState } from "react";

const FormExample: React.FC = () => {
  const [name, setName] = useState("");
  const [email, setEmail] = useState("");

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    alert(`Ad: ${name}, Email: ${email}`);
  };

  return (
    <form onSubmit={handleSubmit} style={{ textAlign: "center" }}>
      <input
        type="text"
        placeholder="Adınızı girin"
        value={name}
        onChange={(e) => setName(e.target.value)}
      />
      <br /><br />
      <input
        type="email"
        placeholder="Email adresi"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
      />
      <br /><br />
      <button type="submit">Gönder</button>
    </form>
  );
};

export default FormExample;

💡 Form input’larını kontrollü hale getirerek state üzerinde tam kontrol sağlarız.

6. useEffect Hook ⏳

useEffect, component render edildikten sonra yan etkileri (side effects) yönetmek için kullanılır. Bunlar genellikle:

  • API çağrıları
  • Timer veya interval başlatma
  • Event listener ekleme/çıkarma

import React, { useEffect, useState } from "react";

const Timer: React.FC = () => {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setSeconds((prev) => prev + 1);
    }, 1000);

    // Cleanup (bellek sızıntısını önler)
    return () => clearInterval(interval);
  }, []);

  return <h2 style={{ textAlign: "center" }}>Geçen Süre: {seconds} sn</h2>;
};

export default Timer;

💡 useEffect, component mount edildiğinde ve dependency array değiştiğinde çalışır. Cleanup fonksiyonu (return kısmı), unmount sırasında veya dependency değiştiğinde çalışır.

📘 Özet

  • Custom Hook: Tekrarlayan mantıkları modüler hale getirir.
  • useState: Component içinde state yönetimi sağlar.
  • useState + Form: Kontrollü form elementleri oluşturur.
  • useEffect: API çağrıları, timer ve event yönetimi gibi yan etkileri kontrol eder.
  • Birden Fazla Hook: Farklı görevleri modüler hale getirerek kodun okunabilirliğini artırır.
