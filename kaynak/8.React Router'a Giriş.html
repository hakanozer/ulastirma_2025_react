React Router’a Giriş 🛣️

React uygulamalarında sayfalar arasında gezinmek için tek sayfa uygulaması (SPA) mantığıyla çalışırız. React Router, SPA yapısında URL yönetimi ve sayfalar arası geçişleri kontrol etmek için kullanılan popüler bir kütüphanedir.

1. React Router Nedir? 🔗

React Router, uygulamanızda farklı sayfalar (routes) oluşturmanıza ve bu sayfalar arasında gezinmenize olanak tanır. Sayfa yenilenmeden farklı bileşenler render edilir. 


// Kurulum
// npm install react-router-dom@6

import { BrowserRouter, Routes, Route } from "react-router-dom";
import Home from "./pages/Home";
import About from "./pages/About";

const App: React.FC = () => {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element=<Home /> />
        <Route path="/about" element=<About /> />
      </Routes>
    </BrowserRouter>
  );
};

export default App;

Burada:

  • BrowserRouter: Tüm router yapısını kapsar.
  • Routes: Route’ları gruplar.
  • Route: Belirli path ve element eşlemesi yapar.

2. Link ve NavLink 🔗

Sayfalar arasında gezinmek için Link veya NavLink kullanılır. Fark: NavLink, aktif route olduğunda CSS sınıfı ekleyebilir. 


import { Link, NavLink } from "react-router-dom";

const Navbar: React.FC = () => {
  return (
    <nav style={{ textAlign: "center", margin: "20px" }}>
      <Link to="/" style={{ margin: "10px" }}>Anasayfa</Link>
      <Link to="/about" style={{ margin: "10px" }}>Hakkımızda</Link>
      <br /><br />
      <NavLink to="/" style={({ isActive }) => ({ fontWeight: isActive ? "bold" : "normal" }) }>Anasayfa (NavLink)</NavLink>
      <NavLink to="/about" style={({ isActive }) => ({ fontWeight: isActive ? "bold" : "normal" }) }>Hakkımızda (NavLink)</NavLink>
    </nav>
  );
};

export default Navbar;

3. Router Özellikleri ⚙️

React Router önemli özellikler sunar:

  • Nested Routes: İç içe route’lar oluşturabilirsiniz.
  • Route Params: Dinamik URL parametreleri yakalayabilirsiniz.
  • Navigate: Programatik yönlendirme yapabilirsiniz.
  • Outlet: Nested route içeriklerini render eder.

4. Route Parametreleri 📌

Dinamik sayfalar oluşturmak için route parametreleri kullanılır. Örnek: /user/5 gibi bir URL. 


import { useParams } from "react-router-dom";

const UserProfile: React.FC = () => {
  const { id } = useParams<{ id: string }>();
  return <h2>Kullanıcı ID: {id}</h2>;
};

export default UserProfile;


// App.tsx
<Route path="/user/:id" element=<UserProfile /> />

Bu sayede URL’deki id değerine erişebilir ve ilgili kullanıcı bilgilerini render edebilirsiniz.

5. React Router Switch Tag (v6 Routes)

React Router v6’da Switch yerine Routes kullanılır. Routes, eşleşen ilk route’u render eder ve eskiden Switch olarak bilinen mantığı sağlar. 


import { Routes, Route } from "react-router-dom";

<Routes>
  <Route path="/" element=<Home /> />
  <Route path="/about" element=<About /> />
  <Route path="*" element=<NotFound /> /> // 404
</Routes>

💡 Özet: v6 ile Routes artık tüm switch mantığını yönetir ve nested routing daha kolaydır.

📘 Özet

  • React Router: SPA uygulamalarında sayfa ve URL yönetimi sağlar.
  • Link & NavLink: Sayfa geçişleri sağlar, NavLink aktif route’u işaretler.
  • Route Özellikleri: Nested routes, parametreler, navigate ve outlet ile zengin routing yapısı.
  • Route Parametreleri: Dinamik sayfa oluşturmak için kullanılır.
  • Switch → Routes: v6’da Switch yerine Routes kullanılır ve eşleşen ilk route render edilir.
