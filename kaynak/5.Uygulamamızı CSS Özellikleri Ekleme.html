React’te Stil Yönetimi ve Event Handling 🎨⚙️

React sadece etkileşimli bir arayüz oluşturmakla kalmaz, aynı zamanda görsel açıdan güçlü ve dinamik uygulamalar tasarlamamıza da olanak tanır. Bu bölümde CSS ekleme yöntemlerini, React Developer Tools kullanımını ve event (olay) yönetimini öğreneceğiz.

5. Uygulamamıza CSS Özellikleri Ekleme 🎨

React uygulamasında stil vermenin birkaç farklı yöntemi vardır. En sık kullanılan yöntemler şunlardır:

  • Harici CSS dosyası eklemek
  • Inline (satır içi) stil kullanmak
  • CSS Modules yapısını kullanmak

👉 Harici CSS Dosyası Kullanımı

Klasik yaklaşım olan harici CSS dosyalarıyla stillendirme oldukça basittir. 


// App.tsx
import "./App.css";

function App() {
  return <h1 className="title">Merhaba React! 👋</h1>;
}

export default App;


/* App.css */
.title {
  color: #007bff;
  text-align: center;
  margin-top: 30px;
  font-family: "Arial";
}

Bu yöntemle CSS dosyasını import edip doğrudan className üzerinden kullanabiliriz.

👉 Inline (Satır İçi) Stil Kullanımı

Bazı durumlarda, dinamik olarak değişen stiller için inline stil kullanmak daha uygundur. 


function InlineStyleExample() {
  const style = {
    color: "white",
    backgroundColor: "teal",
    padding: "10px",
    borderRadius: "8px",
    textAlign: "center",
  };

  return <h2 style={style}>Inline Style Örneği 🌈</h2>;
}

export default InlineStyleExample;

React’te inline stil kullanırken CSS özellikleri camelCase biçiminde yazılır (örneğin backgroundColor).

6. React Developer Tools 🔍

React Developer Tools, geliştiricilerin React bileşenlerini ve state yapısını kolayca incelemesini sağlayan güçlü bir tarayıcı eklentisidir.

Kurulum:

  • Chrome Web Store’a gidin → “React Developer Tools” eklentisini yükleyin.
  • Tarayıcıda React uygulamasını açın.
  • DevTools’ta “Components” ve “Profiler” sekmeleri görünecektir.

Kullanım Alanları:

  • Component hiyerarşisini görüntüleme
  • Props ve state değerlerini inceleme
  • Performans ölçümleri yapma (Profiler sekmesi)

💡 Özellikle “Components” sekmesinde her bileşenin hangi verileri aldığı, hangi state’leri tuttuğu ve nasıl render edildiği rahatlıkla izlenebilir.

7. Uygulamamızı Stillendirme 🎭

Şimdi React bileşenimize biraz stil ekleyerek görsel olarak geliştirelim. Hem harici CSS hem de inline stilleri birlikte kullanalım. 


// StyledCard.tsx
import "./Card.css";

type CardProps = {
  title: string;
  description: string;
};

const StyledCard: React.FC<CardProps> = ({ title, description }) => {
  return (
    <div className="card">
      <h2>{title}</h2>
      <p>{description}</p>
    </div>
  );
};

export default StyledCard;


/* Card.css */
.card {
  background-color: #f8f9fa;
  border: 1px solid #ccc;
  border-radius: 12px;
  padding: 20px;
  margin: 20px auto;
  width: 300px;
  text-align: center;
  transition: 0.3s;
}

.card:hover {
  transform: scale(1.05);
  box-shadow: 0 4px 8px rgba(0,0,0,0.1);
}

Kullanım:


// App.tsx
import StyledCard from "./StyledCard";

function App() {
  return (
    <div>
      <StyledCard
        title="React CSS Öğreniyoruz 🎨"
        description="Bu bileşen hem harici hem de hover efektli CSS içeriyor."
      />
    </div>
  );
}

export default App;

Sonuç olarak görsel olarak hoş, tekrar kullanılabilir ve sade bir kart bileşeni elde ettik.

8. Event Handler Oluşturma 🖱️

React'te kullanıcı etkileşimlerini yönetmek için event handler kullanılır. Örneğin tıklama, input değişimi veya form gönderme gibi olaylar bu şekilde yönetilir.

👉 onClick Event


import React, { useState } from "react";

const ClickExample: React.FC = () => {
  const [count, setCount] = useState<number>(0);

  const handleClick = () => {
    setCount(count + 1);
  };

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <h2>Tıklama Sayısı: {count}</h2>
      <button onClick={handleClick}>Tıkla! 👆</button>
    </div>
  );
};

export default ClickExample;

Burada:

  • handleClick fonksiyonu bir event handler’dır.
  • onClick attribute’una bu fonksiyon referans olarak verilmiştir.
  • Her tıklamada state güncellenir, component yeniden render edilir.

👉 onChange Event


import React, { useState } from "react";

const InputExample: React.FC = () => {
  const [text, setText] = useState<string>("");

  const handleChange = (event: React.ChangeEvent<HTMLInputElement>) => {
    setText(event.target.value);
  };

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <input type="text" value={text} onChange={handleChange} placeholder="Metin girin..." />
      <p>Girilen Metin: {text}</p>
    </div>
  );
};

export default InputExample;

Bu örnekte, input alanındaki her değişiklik state üzerinde saklanıyor. Bu yapı “controlled component” olarak adlandırılır.

📘 Özet:

  • CSS ekleme yöntemleri: Harici dosya, inline stil, CSS Modules
  • React Developer Tools: Component ve state analizi için kullanılır
  • Stil uygulama: Hover efektleri, geçişler, responsive tasarımlar
  • Event handling: onClick, onChange, onSubmit gibi kullanıcı etkileşimlerini yönetir
