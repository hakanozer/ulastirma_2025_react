React Componentları İç İçe Gösterme (Component Nesting) 🧩

React’te bileşenler (component’ler), küçük yapılardan büyük yapılara doğru bir hiyerarşi içinde oluşturulur. Bu yapıya component nesting (bileşenlerin iç içe kullanılması) denir. Böylece projeler daha düzenli, modüler ve yönetilebilir hale gelir.

1. Uygulama Çalışması

Basit bir blog uygulaması düşünelim. Her Post bileşeni içinde Comment bileşenleri yer alacak. Bu, component nesting’in tipik bir örneğidir. 


import React from "react";

type CommentProps = {
  author: string;
  text: string;
};

const Comment: React.FC<CommentProps> = ({ author, text }) => {
  return (
    <div style={{ marginLeft: "20px", borderLeft: "3px solid #ccc", paddingLeft: "10px" }}>
      <p><strong>{author}:</strong> {text}</p>
    </div>
  );
};

type PostProps = {
  title: string;
  content: string;
};

const Post: React.FC<PostProps> = ({ title, content }) => {
  return (
    <div style={{ border: "1px solid #ddd", padding: "15px", borderRadius: "8px", marginBottom: "15px" }}>
      <h3>{title}</h3>
      <p>{content}</p>
      <Comment author="Hakan" text="Harika yazı olmuş!" />
      <Comment author="Ayşe" text="Oldukça bilgilendirici, teşekkürler!" />
    </div>
  );
};

const App: React.FC = () => {
  return (
    <div>
      <Post title="React Nedir?" content="React, UI geliştirmek için kullanılan bir JS kütüphanesidir." />
    </div>
  );
};

export default App;

Bu örnekte, Post component’i içinde Comment component’leri kullanarak bir iç içe yapı oluşturduk. Bu yapı, büyük uygulamalarda bileşenlerin mantıksal olarak birbirine bağlanmasını kolaylaştırır.

2. React Props Sistemi

React’te props (properties), bir component’e dışarıdan veri göndermenin yoludur. Bir üst bileşen (parent) alt bileşene (child) props aracılığıyla veri aktarır. Props, component’lerin dinamik ve tekrar kullanılabilir olmasını sağlar. 


type CardProps = {
  title: string;
  description: string;
};

const Card: React.FC<CardProps> = ({ title, description }) => {
  return (
    <div style={{ background: "#f9f9f9", padding: "10px", borderRadius: "8px" }}>
      <h4>{title}</h4>
      <p>{description}</p>
    </div>
  );
};

Bu yapı sayesinde, aynı component farklı içeriklerle kullanılabilir. Bu da projede kod tekrarını azaltır.

3. Props ile Child Component’e Data Geçme

Parent component, child component’e props yardımıyla veri aktarabilir. Bu, React’in veri akışının en temel mekanizmasıdır. 


const Parent: React.FC = () => {
  const student = { name: "Mehmet", grade: 92 };

  return <Child name={student.name} grade={student.grade} />;
};

type ChildProps = {
  name: string;
  grade: number;
};

const Child: React.FC<ChildProps> = ({ name, grade }) => {
  return <p>{name} adlı öğrencinin notu: {grade}</p>;
};

Bu yöntem, verinin yukarıdan aşağıya doğru (top-down) akmasını sağlar. React bu sayede bileşenlerin birbirinden bağımsız kalmasına yardımcı olur.

4. Tekrar Kullanılabilir Component Yapısı

React’in gücü, component’lerin tekrar kullanılabilir olmasından gelir. Aynı yapıyı birçok farklı veriyle kullanabilirsiniz. 


const ProductCard: React.FC<{ name: string; price: number }> = ({ name, price }) => {
  return (
    <div style={{ border: "1px solid #ddd", padding: "10px", margin: "5px", borderRadius: "6px" }}>
      <h4>{name}</h4>
      <p>₺{price}</p>
    </div>
  );
};

const App: React.FC = () => {
  return (
    <div style={{ display: "flex" }}>
      <ProductCard name="Kulaklık" price={500} />
      <ProductCard name="Mouse" price={250} />
      <ProductCard name="Klavye" price={350} />
    </div>
  );
};

Bu sayede tek bir component yapısını birçok farklı senaryoda kullanabilirsiniz. Bu yaklaşım, DRY (Don’t Repeat Yourself) prensibine uygundur.

5. Props Children

React’te özel bir prop olan children, component içine dinamik olarak içerik yerleştirmeye yarar. Bu özellik, kapsayıcı (wrapper) bileşenler oluşturmak için kullanılır. 


type CardProps = {
  title: string;
  children: React.ReactNode;
};

const Card: React.FC<CardProps> = ({ title, children }) => {
  return (
    <div style={{ border: "1px solid #bbb", padding: "15px", borderRadius: "8px" }}>
      <h3>{title}</h3>
      <div>{children}</div>
    </div>
  );
};

const App: React.FC = () => {
  return (
    <Card title="React Öğreniyoruz">
      <p>Bu alandaki içerik, children prop'u ile gönderildi.</p>
      <button>Devam Et</button>
    </Card>
  );
};

Bu teknik, esnek ve dinamik bileşen yapıları kurmak için oldukça etkilidir. Örneğin modal, card veya layout bileşenlerinde sıkça kullanılır.

6. Uygulama Çalışması

Şimdi children, props ve component nesting’i birleştirerek basit bir dashboard sayfası yapalım. 


import React from "react";

type WidgetProps = {
  title: string;
  children: React.ReactNode;
};

const Widget: React.FC<WidgetProps> = ({ title, children }) => {
  return (
    <div style={{ border: "1px solid #ccc", padding: "10px", margin: "10px", borderRadius: "6px", width: "200px" }}>
      <h4>{title}</h4>
      <div>{children}</div>
    </div>
  );
};

const Dashboard: React.FC = () => {
  return (
    <div style={{ display: "flex" }}>
      <Widget title="Kullanıcı Sayısı">
        <p>120 aktif kullanıcı</p>
      </Widget>
      <Widget title="Satışlar">
        <p>₺45.000</p>
      </Widget>
      <Widget title="Mesajlar">
        <ul>
          <li>Yeni mesaj 1</li>
          <li>Yeni mesaj 2</li>
        </ul>
      </Widget>
    </div>
  );
};

export default Dashboard;

Bu örnek, children ve component nesting kullanımının pratik bir uygulamasıdır. Her Widget component’i kendi içeriğini dışarıdan children olarak alır.

7. Class Based Component ve Functional Component Arasındaki Farklar

Karşılaştırma Class Component Functional Component
Tanım Şekli class MyComponent extends React.Component const MyComponent: React.FC = () => {...}
Durum Yönetimi (State) this.state ve this.setState() kullanılır. useState Hook’u ile yönetilir.
Yaşam Döngüsü componentDidMount, componentDidUpdate gibi metotlar kullanılır. useEffect Hook’u ile yapılır.
Performans Daha fazla kod ve karmaşıklık içerir. Daha hafif, basit ve performanslıdır.
