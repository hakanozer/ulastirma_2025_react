React Yaşam Döngülerine (Lifecycle) Giriş 🔄

React’te her bileşenin bir yaşam döngüsü (component lifecycle) vardır. Bir component oluşturulduğunda (mount), güncellendiğinde (update) veya kaldırıldığında (unmount) belirli işlemler gerçekleşir. Modern React’te bu işlemler useEffect hook’u ile yönetilir.

Bu konuyu anlamak, özellikle API çağrıları, abonelik işlemleri ve cleanup gibi durumları yönetirken çok önemlidir.

1. JSX Bloklarını Koşullu Render Edelim ⚙️

React'te, koşullu render işlemi (conditional rendering), bir bileşenin durumuna göre JSX bloklarının gösterilmesini veya gizlenmesini sağlar. Yani, bir if veya ternary kontrolüyle kullanıcıya farklı arayüzler gösterebiliriz.

Örnek: Kullanıcının giriş yapıp yapmadığını kontrol eden basit bir component


import React, { useState } from "react";

const ConditionalRender: React.FC = () => {
  const [isLoggedIn, setIsLoggedIn] = useState<boolean>(false);

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      {isLoggedIn ? (
        <h2>Hoş geldin, kullanıcı! 🎉</h2>
      ) : (
        <h2>Lütfen giriş yapın 👋</h2>
      )}

      <button onClick={() => setIsLoggedIn(!isLoggedIn)}>
        {isLoggedIn ? "Çıkış Yap" : "Giriş Yap"}
      </button>
    </div>
  );
};

export default ConditionalRender;

Burada:

  • useState ile bir isLoggedIn durumu oluşturduk.
  • Ternary (koşul ? doğruysa : yanlışsa) yapısıyla JSX'i koşullu olarak render ettik.

Bu teknik, menüler, kullanıcı profilleri veya yönetici sayfaları gibi farklı rollerin farklı arayüzler görmesi gereken projelerde sıkça kullanılır.

2. State'i Props Olarak Kullanma 🔁

React’te state, sadece bulunduğu component içinde tanımlanır. Ancak bu state’i başka bir component’te kullanmak istersek, onu props olarak alt bileşene geçirebiliriz.

Örnek: Bir sayacı alt bileşene gönderelim:


import React, { useState } from "react";

type DisplayProps = {
  value: number;
};

const Display: React.FC<DisplayProps> = ({ value }) => {
  return <h3>Güncel Sayı: {value}</h3>;
};

const CounterApp: React.FC = () => {
  const [count, setCount] = useState<number>(0);

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <Display value={count} />
      <button onClick={() => setCount(count + 1)}>Arttır</button>
      <button onClick={() => setCount(count - 1)} style={{ marginLeft: "10px" }}>Azalt</button>
    </div>
  );
};

export default CounterApp;

Bu örnekte:

  • Parent component’te (CounterApp) bir state tanımladık.
  • Bu state’i props olarak child component’e (Display) aktardık.
  • Parent’ta state değiştiğinde child component otomatik olarak güncellendi.

Bu yapı, bileşenleri küçük, bağımsız ve yeniden kullanılabilir hale getirir. Örneğin: Dashboard → Widget veya Form → Input gibi yapılar bu prensiple oluşturulur.

3. Uygulama Çalışması — Yaşam Döngüsü ve useEffect 🌀

Şimdi bir API’den veri çekip, component yaşam döngüsü mantığını inceleyelim. React’te bu işlemler useEffect hook’u ile yapılır.

useEffect üç temel durumda çalışır:

  • Component ilk yüklendiğinde (componentDidMount)
  • Belirli bir state veya prop değiştiğinde (componentDidUpdate)
  • Component kaldırıldığında (componentWillUnmount)

Örnek: Kullanıcı sayısını gösteren bir simülasyon


import React, { useState, useEffect } from "react";

const UserCounter: React.FC = () => {
  const [userCount, setUserCount] = useState<number>(0);

  // Component yüklendiğinde çalışır
  useEffect(() => {
    console.log("Component yüklendi ✅");
    const interval = setInterval(() => {
      setUserCount((prev) => prev + 1);
    }, 1000);

    // Cleanup (component kaldırıldığında çalışır)
    return () => {
      console.log("Component kaldırıldı 🧹");
      clearInterval(interval);
    };
  }, []); // Boş bağımlılık: sadece ilk yüklemede çalışır

  return (
    <div style={{ textAlign: "center", marginTop: "30px" }}>
      <h3>Aktif Kullanıcı Sayısı: {userCount}</h3>
      <p>(Her 1 saniyede bir kullanıcı artıyor...)</p>
    </div>
  );
};

export default UserCounter;

Bu örnekte:

  • useEffect component yüklendiğinde bir interval başlattı.
  • Cleanup kısmında (return fonksiyonu) bu interval temizlendi.
  • Bu yapı, React’in yaşam döngüsünü fonksiyonel component mantığıyla yönetmemizi sağlar.

📘 Özet:

  • Koşullu render, kullanıcıya duruma göre farklı JSX blokları göstermeyi sağlar.
  • State'i props olarak kullanmak, bileşenler arasında veri paylaşımını mümkün kılar.
  • useEffect hook’u, React bileşenlerinin yaşam döngüsünü yönetmek için kullanılır.
  • Cleanup fonksiyonu, bellek sızıntılarını engeller ve component kaldırıldığında çalışır.
