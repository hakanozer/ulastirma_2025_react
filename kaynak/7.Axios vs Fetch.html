React’te API İstekleri: Axios vs Fetch ve JWT Yönetimi 🌐🔐

React uygulamalarında API ile iletişim çok önemlidir. Veri çekme ve gönderme işlemleri için iki temel yöntem vardır: fetch ve axios. Ayrıca modern web uygulamalarında JWT (JSON Web Token) ile kimlik doğrulama ve global kontrol önemlidir.

1. Axios vs Fetch ⚡

API çağrıları yaparken fetch ve axios arasındaki farkları bilmek önemlidir:

Özellik Fetch Axios
Syntax Native, promise tabanlı Daha kısa ve kolay, promise tabanlı
Response Manual JSON parse gerekir Otomatik JSON parse
Hata Yönetimi .then + .catch Daha kapsamlı; status kontrolü kolay
Request Timeout Manuel implement Varsayılan destek
Intercept Yok Request & Response interceptors

💡 Özet: Fetch basit ve native bir çözüm sunarken, Axios daha profesyonel projelerde kolaylık ve ek özellikler sağlar.

2. Axios ile API'a İstek Atma 🔄


import React, { useState, useEffect } from "react";
import axios from "axios";

type User = {
  id: number;
  name: string;
  email: string;
};

const AxiosExample: React.FC = () => {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const response = await axios.get("https://jsonplaceholder.typicode.com/users");
        setUsers(response.data);
      } catch (error) {
        console.error("Hata oluştu:", error);
      } finally {
        setLoading(false);
      }
    };
    fetchUsers();
  }, []);

  if (loading) return <p>Yükleniyor...</p>;

  return (
    <div style={{ textAlign: "center" }}>
      <h2>Kullanıcı Listesi (Axios)</h2>
      <ul>
        {users.map((user) => (
          <li key={user.id}>{user.name} - {user.email}</li>
        ))}
      </ul>
    </div>
  );
};

export default AxiosExample;

3. API’dan Gelen Data ile Component’u Render Etme 🖥️

Axios ile çekilen veriyi state’e kaydettikten sonra, component içinde render edebiliriz. Bu sayede veri güncellendiğinde UI otomatik olarak değişir. 


// UserCard.tsx
import React from "react";

type User = {
  id: number;
  name: string;
  email: string;
};

type Props = {
  user: User;
};

const UserCard: React.FC<Props> = ({ user }) => {
  return (
    <div style={{
      border: "1px solid #ccc", 
      margin: "10px", 
      padding: "10px", 
      borderRadius: "8px"
    }}>
      <h3>{user.name}</h3>
      <p>{user.email}</p>
    </div>
  );
};

export default UserCard;


// App.tsx
import React, { useEffect, useState } from "react";
import axios from "axios";
import UserCard from "./UserCard";

const App: React.FC = () => {
  const [users, setUsers] = useState<any[]>([]);

  useEffect(() => {
    axios.get("https://jsonplaceholder.typicode.com/users")
      .then(res => setUsers(res.data))
      .catch(err => console.error(err));
  }, []);

  return (
    <div style={{ textAlign: "center" }}>
      <h2>User Cards</h2>
      {users.map(user => <UserCard key={user.id} user={user} />)}
    </div>
  );
};

export default App;

5. JWT Değeri ve Kullanımı 🔑

JWT (JSON Web Token), kullanıcının kimliğini doğrulamak ve yetkilendirme yapmak için kullanılır. React tarafında JWT genellikle localStorage veya sessionStorage içinde saklanır. 


// Token saklama
localStorage.setItem("token", "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...");

// Token okuma
const token = localStorage.getItem("token");

JWT ile API isteklerinde header içinde token göndermek güvenli bir yöntemdir:


axios.get("https://api.example.com/protected", {
  headers: { Authorization: `Bearer ${token}` }
});

6. Global JWT Control 🌍

Projelerde JWT kontrolünü merkezi bir yerde yönetmek faydalıdır. Bu sayede tüm API çağrıları token ile otomatik çalışabilir ve kullanıcı oturumu global olarak kontrol edilir. 


// axiosInstance.ts
import axios from "axios";

const token = localStorage.getItem("token");

const axiosInstance = axios.create({
  baseURL: "https://api.example.com",
  headers: {
    Authorization: token ? `Bearer ${token}` : "",
  },
});

export default axiosInstance;

// Kullanım
import axiosInstance from "./axiosInstance";

axiosInstance.get("/users")
  .then(res => console.log(res.data))
  .catch(err => console.error(err));

Bu yapı sayesinde:

  • Tüm API istekleri otomatik token içerir
  • Tek bir noktadan token güncellenebilir
  • React component’leri sade ve temiz kalır

📘 Özet

  • Fetch: Native, basit API çağrıları için yeterli.
  • Axios: Daha profesyonel, interceptors, timeout ve kolay JSON parse sağlar.
  • Component render: API’dan gelen veri state’e kaydedilir ve JSX içinde render edilir.
  • JWT: Kullanıcı doğrulaması için token saklanır ve API header’ında gönderilir.
  • Global JWT Control: Tek bir axios instance ile tüm API çağrılarında token yönetimi yapılabilir.
