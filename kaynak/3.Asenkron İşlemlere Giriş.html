React’te Asenkron İşlemlere Giriş ⚙️

Modern web uygulamalarında, asenkron işlemler oldukça yaygındır. Örneğin bir API'den veri çekmek, dosya yüklemek veya form gönderimi yapmak gibi işlemler asenkron şekilde gerçekleşir. React’te bu işlemler, state ve useEffect hook’ları ile birlikte yönetilir.

1. React State

React’te state, bir component’in o anki durumunu saklayan yapıdır. State değiştiğinde React component’i otomatik olarak yeniden render eder. Bu da kullanıcı arayüzünü dinamik hale getirir.

State oluşturmak için: useState hook’u kullanılır.


import React, { useState } from "react";

const Counter: React.FC = () => {
  // useState ile state oluşturuyoruz
  const [count, setCount] = useState<number>(0);

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <h3>Sayaç: {count}</h3>
      <button onClick={() => setCount(count + 1)}>Arttır</button>
      <button onClick={() => setCount(count - 1)} style={{ marginLeft: "10px" }}>Azalt</button>
    </div>
  );
};

export default Counter;

Yukarıdaki örnekte, useState ile bir sayaç oluşturduk. Butonlara tıklandığında state değişiyor ve component yeniden render ediliyor.

Önemli Not: State değişimleri asenkron şekilde gerçekleşir. Bu yüzden, state hemen güncellenmiş gibi davranmak hatalara yol açabilir.

2. Uygulama Çalışması — Asenkron Veri Çekme

Gerçek bir senaryo düşünelim: bir API’den kullanıcı listesi çekmek istiyoruz. React’te bu işlem useEffect hook’u içinde async/await ile yapılır. 


import React, { useState, useEffect } from "react";

type User = {
  id: number;
  name: string;
  email: string;
};

const UserList: React.FC = () => {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState<boolean>(true);

  // Asenkron veri çekme işlemi
  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const response = await fetch("https://jsonplaceholder.typicode.com/users");
        const data = await response.json();
        setUsers(data);
      } catch (error) {
        console.error("Veri çekilirken hata oluştu:", error);
      } finally {
        setLoading(false);
      }
    };

    fetchUsers();
  }, []);

  if (loading) {
    return <p>Yükleniyor...⏳</p>;
  }

  return (
    <div>
      <h2>Kullanıcı Listesi</h2>
      <ul>
        {users.map((user) => (
          <li key={user.id}>
            <strong>{user.name}</strong> - {user.email}
          </li>
        ))}
      </ul>
    </div>
  );
};

export default UserList;

Bu örnekte:

  • useState ile kullanıcı listesini (users) ve yüklenme durumunu (loading) tuttuk.
  • useEffect içinde API çağrısı yaptık.
  • async/await ile asenkron işlemi yönettik.

Bu yapı, gerçek projelerde API'den veri çekme, loading spinner gösterme ve hata yakalama gibi durumları yönetmek için kullanılır.

3. State'i Fonksiyon İçinde Oluşturma

Bazı durumlarda state’i doğrudan component içinde değil, fonksiyonlar veya özel hook’lar (custom hooks) aracılığıyla oluşturmak isteyebiliriz. Bu, kodun tekrar kullanılabilirliğini ve okunabilirliğini artırır.

Örnek: State’i özel bir fonksiyon ile oluşturma


import React, { useState } from "react";

// Özel bir hook tanımlıyoruz
function useCounter(initialValue: number) {
  const [count, setCount] = useState(initialValue);

  const increment = () => setCount((prev) => prev + 1);
  const decrement = () => setCount((prev) => prev - 1);
  const reset = () => setCount(initialValue);

  return { count, increment, decrement, reset };
}

// Ana component
const CounterApp: React.FC = () => {
  const { count, increment, decrement, reset } = useCounter(10);

  return (
    <div style={{ textAlign: "center", marginTop: "20px" }}>
      <h3>Sayı: {count}</h3>
      <button onClick={increment}>Arttır</button>
      <button onClick={decrement} style={{ marginLeft: "10px" }}>Azalt</button>
      <button onClick={reset} style={{ marginLeft: "10px" }}>Sıfırla</button>
    </div>
  );
};

export default CounterApp;

Bu yapıda useCounter adında özel bir hook oluşturduk. Bu hook, state ve fonksiyonları dışarıya döndürür. Böylece aynı mantığı farklı component’lerde tekrar tekrar kullanabiliriz.

🔍 Özet:

  • State: component’in mevcut durumunu tutar ve değiştiğinde yeniden render tetikler.
  • Asenkron işlemler: veri çekme, güncelleme gibi zaman alan işlemleri yönetmek için async/await ve useEffect kullanılır.
  • Custom Hook yapısı: state ve mantığı yeniden kullanılabilir hale getirir.
